KASSIGNER SECURITY FIX RECORD 014

Finding:
Dice, passphrase, seed-manager, cleanup, and encrypted-payload security tests
were optional verbose diagnostics and did not stop startup when they failed.

Branch:
fix/security-tests-fail-closed

Affected files:
bootloader/src/app/boot_test.rs
bootloader/src/ui/setup_wizard.rs
bootloader/src/ui/seed_manager.rs
bootloader/src/hw/sd_backup.rs

Before:
The affected tests were compiled only for test or verbose-boot builds.
Verbose startup printed CRITICAL when they failed but continued booting.
Normal and production firmware did not execute these tests.

After:
Five dice tests run during every boot:
target limits, 12-word golden vector, 24-word golden vector, 500-roll overflow
and undo behavior, and dice-memory zeroization.

Five seed/passphrase tests run during every boot:
fingerprint vectors, seed storage/deletion, 128-byte passphrase boundaries,
passphrase-input zeroization, and fingerprint-collision handling.

The full 128-byte encrypted SD/steganographic round-trip runs during every boot.
Each individual dice and seed test reports OK or FAIL in development/verbose
serial output. Any failed mandatory test permanently stops startup. Firmware
cannot continue into wallet operations after a security-test failure.
